# ЛР 4 + РК 1. Параметрический поиск и объединённая система

* **ЛР 4** — поиск по фильтрам: название (без учёта регистра и диакритики, с нечётким
  совпадением при опечатке), вкус (узлы таксономии), страна, производитель, диапазоны
  крепости / сахара / объёма, класс сладости, горечь, выдержка в дереве. Любой фильтр
  можно не задавать. Ввод проверяется, все ошибки показываются сразу.
* Пустая выдача → «Не найдено точного соответствия, однако, возможно, Вам понравится»:
  объекты ранжируются **функцией полезности** U(x) = Σ w_f·deg_f(x) / Σ w_f (очки за
  совпадение, штраф пропорционален расстоянию до границы фильтра), плюс подсказка,
  какие фильтры ослабить, чтобы появились точные совпадения.
* **РК 1** — единый интерфейс с ЛР 3: поиск → лайки/дизлайки → рекомендации →
  уточнение фильтрами → … История запросов хранится в сессии: к любому шагу можно
  вернуться и уточнять от него, можно начать заново.

Рекомендательное ядро **не копируется**: `bootstrap.py` подключает пакет `recsys`
из `../3-likesdislikes` (каталог, мера близости, стратегии, HTTP-каркас, общие стили и JS).

## Запуск

```bash
python run.py            # http://127.0.0.1:8004/
```

## Структура

```
run.py, bootstrap.py       запуск; подключение модулей ЛР3
search/                    ЛР4: фильтры (Specification), запрос и его разбор (Builder),
                           функция полезности и подсказка ослабления, поисковая система
unified/                   РК1: сессия и история (Memento), операции (Command),
                           фасад, API, интерфейс (static/ + общие файлы ЛР3)
experiments/               сравнение «функция полезности vs ослабление фильтров»
tests/                     unittest, включая проверку «тело метода ≤ 5 строк»
```

## Проверки

```bash
python -m unittest discover -s tests -t .
python experiments/compare_fallback.py
```
