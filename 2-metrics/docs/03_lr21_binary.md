# ЛР 2.1b. Бинарные признаки: ассоциативные меры близости

Признаки `bitter` и `wood_contact` — бинарный вектор длины 2.
По Строганову (2014) для пары объектов считаются величины:

- `a` — позиций, где оба = 1 (положительное совпадение);
- `b` — x=1, y=0; `c` — x=0, y=1 (рассогласования);
- `d` — оба = 0 (отрицательное совпадение); `n = a+b+c+d = 2`.

Кандидаты:

| Мера | Формула | Учитывает 0–0 |
|------|---------|:---:|
| Жаккар | `a / (a+b+c)` | нет |
| Дайс (Сёренсен) | `2a / (2a+b+c)` | нет |
| Сокал–Миченер (simple matching) | `(a+d) / n` | да |
| Роджерс–Танимото | `(a+d) / (a+d+2(b+c))` | да |

Матрицы: `out/matrices/bin_*_sim.csv`, карты: `out/heatmaps/bin_*_sim.png`.

## Тестовые пары (из out/report.txt)

| Пара | Вектора | Жаккар | Дайс | SMC | Р–Т |
|------|---------|--------|------|-----|-----|
| L26–L27 | (0,0)·(0,0) | 1.0* | 1.0* | 1.0 | 1.0 |

заглушку `sim := 1`.

## Экспертная оценка

19 из 30 ликёров имеют вектор (0,0) — «ни горький, ни бочковой» —
и это **содержательное** сходство: оба объекта — негорькие,
недубовые, т.е. десертного типа.

**Жаккар и Дайс отвергнуты**: они игнорируют совпадения по нулям.
Пара L28–L30 (Baileys (0,1) и Advocaat (0,0)) получает близость 0 —
хотя оба ликёра негорькие и различаются лишь в одном признаке.
Хуже того, любая пара (0,0)·(0,0) формально неопределена (0/0).
Для данных, где нулевое значение признака информативно,
нулевые совпадения учитывать обязательно.

**Роджерс–Танимото**: учитывает `d`, но удваивает штраф за
рассогласование. При всего двух признаках одно различие даёт
`sim = 1/3` — шкала пережата, почти все различающиеся пары оказываются
«далёкими». Мера корректна, но для n=2 чрезмерно пессимистична.

**SMC выбран**: `sim = (a+d)/2` — просто доля совпадающих позиций.
Одно совпадение из двух = 0.5, полное = 1.0, полное различие = 0.
Линейна, интерпретируема, не имеет неопределённостей, все
требования к близости выполнены: `sim ∈ [0,1]`, `sim(x,x)=1`,
симметрична.

## Итог

**Бинарная частная мера — Сокал–Миченер (simple matching).**
Замечание: при расширении набора бинарных признаков (например,
теги-ингредиенты) имеет смысл пересмотреть выбор в пользу Жаккара
или Роджерс–Танимото — при длинных разреженных векторах совпадения
по нулям перестают быть информативными.
