# Теория: расстояние, близость, нормировка, суммирование мер

Источники: Большакова Е.И., Клышинский Э.С., Ландэ Д.В., Носков А.А.,
Пескова О.В., Ягунова Е.В. «Автоматическая обработка текстов на
естественном языке и компьютерная лингвистика», МИЭМ, 2011,
разд. 2.7.2 «Меры близости и расстояния»; Строганов Ю.В. «Об
ассоциативных бинарных мерах близости документов и приложения к
классификации», 2014, с. 421–432.

## Расстояние

Расстояние `d(x,y)` — мера **различия**: при `x = y` (в терминах книги
`d_i = d_j`) расстояние равно **0**. Область значений в общем случае
`[0, +∞)`; для сопоставимости с другими мерами удобно использовать
**нормированное расстояние** `∈ [0,1]`.

Свойства метрики: `d(x,x)=0`, `d(x,y)≥0`, симметрия `d(x,y)=d(y,x)`,
неравенство треугольника `d(x,z) ≤ d(x,y)+d(y,z)`.

## Близость (сходство)

Близость `sim(x,y)` — мера **сходства**: `sim ∈ [0,1]`, при `x = y`
требуется `sim(x,y) = 1` (объекты идентичны).

## Связь расстояния и близости

Обратно пропорциональны. Стандартные переходы:

- для нормированного расстояния: `sim = 1 − d`;
- для ненормированного: `sim = 1 / (1 + d)` или `sim = exp(−d)`.

В работе все расстояния нормированы в `[0,1]`, поэтому используется
простейший переход `sim = 1 − d`.

## Зачем нормировать признаки

Признаки имеют разный масштаб: `sugar_gpl` ∈ [80, 400] г/л,
`abv_pct` ∈ [15, 55] %, `volume_l` ∈ [0.5, 1.0] л. Без нормировки
разность в 10 г/л сахара даст больший вклад, чем разность в 20 %
крепости, — ось с крупным масштабом «перевесит» остальные
(пример из лекции: число комнат vs цена квартиры).

Используется **min-max нормировка**: `x' = (x − min) / (max − min)`,
все оси → `[0,1]`, единый масштаб уравнивает веса координат.

После этого нормированные меры дают `d ∈ [0,1]`:

- `d_manh = (1/D)·Σ|x_d − y_d|`
- `d_eucl = sqrt((1/D)·Σ(x_d − y_d)²)`
- `d_cheb = max_d |x_d − y_d|`

## Матрица смежности

Для каждой меры `g` строится матрица `G` размера `n×n`,
`G_ij = g(o_i, o_j)`, `i,j = 1..n`. Матрица симметрична; на диагонали
0 для расстояния и 1 для близости. Визуализация — тепловая карта
(`out/heatmaps/*.png`).

## Можно ли складывать меры?

Да. **Взвешенная сумма** `Σ ω_k·g_k` мер, приведённых к одной шкале
`[0,1]`, при `Σ ω_k = 1`, `ω_k ≥ 0` сама остаётся мерой в `[0,1]`:

- сумма метрик — метрика (аксиомы сохраняются);
- выпуклая комбинация близостей ∈ [0,1], на диагонали = 1.

Без нормировки шкал складывать нельзя — мера с большим диапазоном
задавит остальные. Именно поэтому все частные меры заранее приведены
к `[0,1]`. Это основа ЛР 2.3.
