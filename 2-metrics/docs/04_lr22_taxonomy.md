# ЛР 2.2. Мера близости по таксономии вкуса

Признак `taste` — метка класса с иерархией L1/L2/L3
(`Травяные/Смесь трав/Амаро`, `id_path` вида `H-M-A`). Обычная
δ-функция «совпало/нет» теряет структуру: пара «Амаро–Амаро» и пара
«Амаро–Дынно-банановые» обе дали бы 0, хотя первые — родственники
внутри «Травяных/Смеси трав», а вторые — из разных ветвей.
Поэтому нужна **графовая мера** на дереве таксономии.

## Обзор графовых мер на таксономии

Таксономия — дерево; каждая метка класса — узел (у нас — лист
глубины 3). Все графовые меры строятся вокруг двух идей:
**длина пути** между узлами и **общий предок** (LCA — least common
ancestor, наиболее глубокий узел, под которым лежат оба).

### 1. Реберные меры (edge-based / path length)

**Расстояние кратчайшего пути (edge counting, Rada et al., 1989).**
`d_path(x,y)` = число рёбер на кратчайшем пути. В дереве это всегда
путь «вверх до LCA, вниз до y»:

`d_path = depth(x) + depth(y) − 2·depth(LCA)`

У нас: тот же лист → 0; общий L2 → 2; общий L1 → 4; разный L1 → 6.
Плюс — простая настоящая метрика. Минус — «линейка без учёта
глубины»: два листа под общим L2 и два узла верхнего уровня получают
одинаковое расстояние, хотя чем глубже общий предок, тем конкретнее
сходство. Также требует нормировки на высоту дерева.

**Ликок–Чодороу (Leacock–Chodorow, 1998).**
`sim_LCh = −log( d_path / (2·D_max) )`, где `D_max` — максимальная
глубина дерева (у нас 3). Путь нормируется на размер дерева,
логарифм сглаживает шкалу. Содержательно близка к edge counting,
но явно учитывает высоту дерева.

**У–Палмер (Wu–Palmer, 1994).**
`sim_WP = 2·depth(LCA) / (depth(x) + depth(y))`.
Ключевое отличие от edge counting: в числителе **глубина общего
предка** — два «глубоких» родственника (общий L2 на глубине 2)
ближе, чем два «мелких» (общий L1). При этом sim(x,x) = 1
автоматически, область [0,1] — нормировка встроена.

**Взвешенный общий путь.**
Обобщение: ребру уровня `l` приписывается вес `w_l`;
`sim = Σ_{общие уровни} w_l / Σ_{все} w_l`. При `w1=w2=w3=1` совпадает
с У–Палмером (общий L2 → 2/3, общий L1 → 1/3). Позволяет ставить
«разные веса на уровнях/подклассах» из задания: например
`w = (1,2,3)` усилит цену совпадения L3.

### 2. Узловые меры (information content, node-based)

Требуют вероятности `p(c)` узла (частоты встречаемости класса в
корпусе/выборке); `IC(c) = −log p(c)` — информационная
ёмкость: чем реже понятие, тем оно информативнее.

- **Резник (Resnik, 1995)**: `sim = IC(LCA)` — сходство равно
  информативности наиболее специфичного общего предка.
- **Лин (Lin, 1998)**: `sim = 2·IC(LCA) / (IC(x) + IC(y))` —
  нормированный Resnik, [0,1].
- **Цзян–Конрат (Jiang–Conrath, 1997)**: расстояние
  `d = IC(x) + IC(y) − 2·IC(LCA)` — разность ёмкостей.

В нашей задаче `p(c)` брать неоткуда: таксономия авторская на
30 объектов, корпуса встречаемости нет. Можно оценить `p(c)` долей
объектов датасета под узлом, но при 30 записях оценки шумные —
поэтому узловые меры здесь неприменимы содержательно и остаются
«на вырост».

### 3. Гибридные

- **Ли и др. (Li et al., 2003)**: нелинейная комбинация длины пути
  `l` и глубины LCA `h`:
  `sim = e^{−αl} · (e^{βh} − e^{−βh}) / (e^{βh} + e^{−βh})` —
  два параметра подгонки, для учебного дерева из 3 уровней
  избыточна.

## Выбранная мера: У–Палмер

`sim_WP(x,y) = 2·depth(LCA(x,y)) / (depth(x) + depth(y))`

глубины: корень = 0, L1 = 1, L2 = 2, L3 = 3 (все метки — листья
глубины 3).

Эквивалентна взвешенному общему пути с `w1 = w2 = w3 = 1` —
«разные веса на уровнях» поддерживаются параметрически, но на
3-уровневом дереве равные веса дают естественную градацию без
подгонки. Выбрана потому что:

- учитывает глубину общего предка (в отличие от edge counting);
- не требует корпусных частот (в отличие от Resnik/Lin/Jiang–Conrath);
- самонормирована в [0,1], `sim(x,x)=1`, симметрична;
- устойчива к расширению дерева (появится L4 — формула не меняется).

## Значения меры

| Ситуация | depth(LCA) | sim | Пример |
|----------|-----------|-----|--------|
| Полное совпадение L1+L2+L3 | 3 | 1.000 | L05–L07 (оба «Амаро»), L04–L03 (оба «Кройтер») |
| Общий L2, разный L3 | 2 | 0.667 | L20–L21 («Ядра косточковых»: марципан vs миндаль) |
| Общий L1, разный L2 | 1 | 0.333 | L01–L03 (оба «Травяные»: однотравные vs смесь) |
| Разный L1 | 0 | 0.000 | L08–L26 («Фруктовые» vs «Обжаренные») |

Проверка на данных (`out/report.txt`) подтверждает ожидания.

Сопутствующее расстояние: `d = 1 − sim`. Оно согласовано с
реберным расстоянием: `d_path / 6 = (6 − 2·shared)/6 = 1 − sim` —
та же мера в единицах «доля пути».
