# ЛР 2. Меры близости и расстояния (ликёры, n = 30)

Схема гетерогенная, поэтому для каждого типа признака выбрана своя
частная мера, а итоговая мера — их взвешенная сумма.

| Признак                          | Тип                | Частная мера                          |
|----------------------------------|--------------------|---------------------------------------|
| `abv_pct`, `sugar_gpl`, `volume_l` | числовые         | норм. евклидово расстояние (ЛР 2.1)   |
| `bitter`, `wood_contact`         | бинарные           | Сокал–Миченер / simple matching (SMC) |
| `taste` (L1/L2/L3)               | иерархия (метка)   | У–Палмер по таксономии (ЛР 2.2)       |
| `sugar_class`                    | порядковый (лингв.)| 1 − \|ord(x)−ord(y)\| / 3 (4 терма)   |
| `country`, `producer`            | номинальные        | δ-функция (1 — совпали, 0 — нет)      |
| `id`, `name`, `notes`, `source_quality` | —            | не участвуют (служебные/текст)        |

`sugar_class` — лингвистическая переменная по сахару:
малосладкий < 200, умеренный 200–250, сладкий 250–350,
crème ≥ 350 г/л (250 г/л — порог EU «crème»).

## Запуск

```bash
pip install -r requirements.txt
python metrics.py
```

## Итоговая мера

`sim(x,y) = 0.35·sim_taste + 0.30·(1−d_euclid) + 0.15·sim_SMC
          + 0.10·sim_sugar_class + 0.05·δ_country + 0.05·δ_producer`

`dist(x,y) = 1 − sim(x,y)`, обе величины ∈ [0,1].
