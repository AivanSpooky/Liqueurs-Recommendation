# ЛР 3. Контентная рекомендательная система ликёров

Три версии системы (ПСВ) на итоговой мере близости из ЛР 2:

| Версия | Вход | Выход |
|---|---|---|
| **v1** | один ликёр-затравка | список, ранжированный по убыванию близости к затравке |
| **v2** | набор лайков (порядок = время установки) | ранжированный список |
| **v3** | лайки и дизлайки | ранжированный список |

## Запуск

```bash
python run.py            # http://127.0.0.1:8003/ откроется в браузере
python run.py --port 9000 --no-browser
```

Внешних зависимостей у системы нет — только стандартная библиотека Python ≥ 3.10.
`matplotlib` нужен лишь для графиков сравнения подходов (`experiments/plots.py`).

## Принятые решения (подробно — отчёт, глава 3)

* **v2 — подход Г «группы лайков»**: лайки объединяются в группы интересов
  (single linkage, ребро при sim ≥ θ = 0.65), внутри группы — среднее близостей,
  выдача сшивается по одному объекту от каждой группы без дубликатов.
  Альтернативы реализованы и сравниваются: А — среднее, Б — с учётом времени,
  В — взвешенная сумма (баланс групп), максимум, Г′ — сшивание списков по каждому лайку.
* **v3 — контрастный штраф**: `score − β·max(0, sim(x, дизлайк) − sim(x, ближайший лайк))`, β = 1.
  Штрафуется только то, что ближе к дизлайку, чем к любому лайку, поэтому дизлайк
  одного объекта не «портит» любимый жанр. Альтернативы: только исключить дизлайки,
  исключить похожие (порог τ), вычитание (как в формуле Роккио).
* Каждая рекомендация объясняется: ближайший лайк и вклад частных мер в близость.

## Структура

```
run.py                     запуск веб-интерфейса
recsys/
  domain/                  модель ликёра, каталог (Repository), таксономия вкуса
  similarity/              частные меры, итоговая мера (Composite), фабрика, матрица смежности
  recommend/               стратегии лайков и дизлайков (Strategy), проверка запроса, рекомендатель
  service.py               фасад для интерфейсов ЛР3 и ЛР4
  web/                     HTTP-каркас на stdlib, API, HTML5-интерфейс (static/)
experiments/               офлайн-сравнение стратегий: evaluate.py → out/*.csv, plots.py → out/*.png
tests/                     unittest: совпадение с матрицей ЛР2, стратегии, валидация, HTTP, код-стайл
tools/method_length.py     проверка правила «тело метода — не более 5 строк»
```

## Проверки

```bash
python -m unittest discover -s tests -t .
python tools/method_length.py .
python experiments/evaluate.py && python experiments/plots.py
```
